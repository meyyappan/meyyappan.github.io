      Introduction

      Have you ever experienced not having something your whole life, then getting it and wondering how you lived without it? That’s how I feel about Qubes OS. I’ve used many operating sytems throughout my life, Windows, Mac OS, Ubuntu, and a few other Linux distros. But by far, I’ve been enjoying Qubes OS the most.

      Motivation

      Before using Qubes I used to run separate virtual machines (VMs) for each project that I was working on. For example, when I was looking to buy a car, I spun up a VM just for that. Within that VM I would record notes, download PDF guides, modify the browser bookmarks to

      • Project isolation

      • Tinkering

      • Custom browser behaviour

      Alternatives

      • Running multiple VMs

      • Resource heavy

      • Storage heavy

      • Relatively slow to spin up a new environment

      Other Uses

      • Security, e.g. using scanners

      Install Developer Template Qube

      1. Cloned debian-12-xfce and created a template vm

      2. Downloaded in a disp qube .deb files for installing docker, vscode, and marktext.

      3. qube copy to the template vm

      4. install the deb files using sudo apt install ./{}.deb

      5. create a directory in /etc/skel called preinstalled

      6. moved all the deb files into that directory

      7. Follow these inst to create a disp vm based on the template vm

        1. https://www.qubes-os.org/doc/disposable-customization/#creating-a-new-disposable-template
      [user@dom0 ~]$ qvm-create --template <TEMPLATE> --label red <DISPOSABLE_TEMPLATE>
[user@dom0 ~]$ qvm-prefs <DISPOSABLE_TEMPLATE> template_for_dispvms True
[user@dom0 ~]$ qvm-features <DISPOSABLE_TEMPLATE> appmenus-dispvm 1

      Automount Folder

      sudo apt install gvfs-backends smbclient cifs-utils


vi /root/.smbcredentials
chmod 400 /root/.smbcredentials
mkdir /media/share

vi /root/.smbcredentials
vi:
username=TruenasUsername
password=TruenasPassword

vi /etc/fstab
vi:
//192.168.2.40/keepass /media/truenas/keepass cifs vers=3.0,credentials=/root/.smbcredentials,file_mode=0777,dir_mode=0777,uid=1000,gid=1000
